# 🛒 Swagimals — E-Commerce Platform

- Full-stack MERN e-commerce platform built and led as a team project.
- Three separate repositories: Admin UI, Customer Portal, API Server.

## 🧩 System Overview
Swagimals-Customer     ← Customer-facing React storefront
Swagimals-AdminUI      ← Admin portal for inventory and order management
Swagimals-APIServer    ← Shared Node.js + Express REST API backend
